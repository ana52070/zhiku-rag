## 已处理的问题

- Python 3.10 不支持 unittest.TestCase.enterContext，已使用兼容的清理注册方式。
- 本机 HTTP 客户端继承 SOCKS 代理而缺少依赖，测试用 localhost 直连；运行依赖加入 httpx SOCKS 支持。
- 首次后端提交时 PowerShell 批量命令未在 MCP 测试失败后停止；随后已单独修正并验证，保留修正提交作为记录。
- Docker 环境 Host 白名单与 TestClient 默认 testserver 不一致，测试已统一使用 localhost，生产默认白名单不再包括 testserver。
- 新版 pydantic-settings 与固定 MCP SDK 出现前向引用警告，已固定经过验证的 Pydantic 与 settings 版本；最终镜像测试未再出现该警告。

## 验收边界

**已证实：** 功能流程、持久化、访问保护、真实 MCP 协议交互、实际浏览器操作与 Docker 可运行性。

**未验证：** 用户真实 embedding 服务的连接、费用、额度与语义检索质量；公网反向代理/HTTPS；大规模数据与多人并发；未提供的扫描件 OCR 和 Excel/CSV 功能。MVP 使用同步请求内索引与逐段余弦检索，适用于先验证个人知识库流程。

第一步实用验收：在网页配置自己的 embedding 接口，连接测试成功后保存，上传一份小文件，提出一个能从原文明确找到答案的问题，再检查返回来源是否正确。
