## 部署附加配置

- 管理令牌与公开引用地址保存在服务器私有 `data/runtime-authorization.env`，systemd drop-in 为 `/etc/systemd/system/zhiku-rag.service.d/authorization.conf`。
- OpenClaw 全库 Key 配置在已有 MCP 连接的 `headers.Authorization`，其余模型与飞书配置保留。
- 旧服务关闭时等待 MCP 长连接，触发 systemd 90 秒停止超时。部署改为先停调用端；新 RAG 启动参数增加 `--timeout-graceful-shutdown 15`，systemd 停止超时 30 秒。
- VPS 已有 `/tmp/inspect.py` 会遮蔽 Python 标准库；一次性部署脚本采用 `python -I` 隔离模式，不删除该无关文件。应用与测试在项目目录运行。
