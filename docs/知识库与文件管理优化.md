# 知识库与文件管理优化

日期：2026-10-09。

## 操作方式

- 知识库支持新建、查看、改名、删除。原“默认知识库”迁移为普通的“待整理资料”，原有文件 ID、文字、索引和文件内容保留。
- 删除知识库前显示文件数量并要求确认；确认后删除全部文件、嵌套文件夹和向量。删除后的库不会因重启重新出现。
- 文件列表支持逐项勾选、全选当前列表、批量删除和移动。移动可选择当前库或其他库的根目录、任意子文件夹。切换目录或过滤列表时清除不在当前列表的选择，避免误操作。
- 批量操作先验证所有文件和目标位置，再修改数据库；错误请求不会只改动部分文件。移动保留 ID 和原索引，授权随新知识库范围生效。
- 预览覆盖 TXT、Markdown、文字 PDF、DOCX、XLSX、PPTX、CSV。PDF 使用原始文件页面；Word 展示正文与表格，Excel/CSV 展示表格，PPT 按页展示文本与表格。Office 为内容预览，不承诺与原软件版式一致。图片、图表和复杂对象不保证呈现。
- 管理员可以在暂停业务或禁用文件时预览，并切换到分页提取原文。Agent 的检索、读取权限不会因此放宽。
- 当前知识库使用蓝色边框、底色和明显标记。
- “服务与接入”提供 OpenClaw 配置 JSON、通用 MCP JSON 和自动配置提示词。填写只读 API Key 后复制；不应在此填写管理员令牌。实际字段需以目标客户端安装版本为准。
- Key 支持创建、改名/修改授权、撤销和永久删除。已撤销记录也提供删除按钮。永久删除立即使 Key 和已发出的文件下载授权失效。
- API Key 只保存摘要，明文仍只在创建时显示；删除全部 Key 后也不会开放匿名 MCP 访问。

## 验证

- 后端测试覆盖旧数据库迁移、删除后重启、批量操作校验与索引保留、七种格式预览、文档脚本隔离和只读权限边界。
- 三组浏览器验收覆盖原有管理流程、嵌套目录与授权、新增多选批量管理、PDF/Markdown 预览、配置生成及响应式布局。
- 本地 embedding 使用测试替身；公网部署验证沿用已有模型与凭证，不修改原业务文件。

## 部署

升级前停止调用端和 RAG，备份整个数据目录与旧提交；同步 GitHub 已发布提交，安装固定依赖后重启。管理员令牌和 OpenClaw Key 保持不变。

公网测试只操作临时测试库、测试文件及临时 Key，结束后清除。升级前后比较原文件 SHA-256、文件 ID、索引状态和全部原向量。
