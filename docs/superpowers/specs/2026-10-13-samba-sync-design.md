# Samba 知识库增量同步设计

用户已于 2026-10-13 确认本方案并授权开发、测试及部署到内网服务器。

## 目标与边界

RAG 是 SMB 客户端，访问已有远端 Samba 共享。沿用 Rust 核心与 Python 文档 Worker，不搭建 Samba 服务。网页配置共享根目录、账号密码、扫描子目录、目标知识库和子目录、时区、每日/每周/间隔/Cron、启停状态，并提供连接测试、立即同步、执行记录。

## 同步规则

- 源相对路径标识文件，SHA-256 标识内容。保留源目录层级；未变文件不重复解析或调用 embedding。
- 共享为准：首次自动接管目标相同路径同名文档，人工移动或删除后恢复源状态。多个同名目标或任务所有权冲突报错，避免任意选取。
- 修改时先读取稳定文件、解析、生成并校验向量，再用事务提交文档、向量、来源映射。准备失败保留原可检索版本。
- 原文件使用不可变存储文件名，事务切换引用，避免原文件与索引出现半更新。
- 只删除本任务关联的文档，且须完整扫描成功；网络、权限、读取失败时取消删除阶段。
- 支持的文件类型沿用解析器；忽略 Office 锁文件及临时文件；不跟随链接。删除源空目录不自动删除知识库空文件夹。
- 改名视为删除旧路径、新增新路径，不承诺保留旧 ID 或历史版本。

## 组件与安全

- Python Worker 提供内部连接测试、完整清单和受限文件读取；每请求隔离 SMB 会话与凭据，防止不同任务账号串用。
- Rust 保存加密凭据、任务、文件映射及执行记录；持久化下次时间，单实例调度且全局同步互斥，重启标记中断任务并补执行一次到期任务。
- Cron 接受标准五字段，时区默认 Asia/Shanghai；常用模式转换为等价规则。间隔按执行开始时间计，错过多次不连续补跑。
- 同步管理接口校验管理员令牌；Worker 的 SMB 路由使用独立内部令牌，凭据不返回前端、不写日志、不提交 Git。
- 已同步文件存在时不允许直接更改源根目录和目标位置；需新建任务，防止配置变化触发误删除。可修改凭据、时间和启停。

## 验证与部署

测试覆盖首次接管、重复执行、修改、删除、人工移动/删除恢复、嵌套目录、故障保留旧索引、扫描失败不删除、跨任务冲突、凭据隐藏、鉴权、时区/Cron、重启恢复及并发保护。先本地验证，再只读核实内网部署、完整备份数据库/原文件/密钥、发布、检查服务和回滚路径。真实 Samba 联调需用户提供共享地址并在配置页填写凭据。
