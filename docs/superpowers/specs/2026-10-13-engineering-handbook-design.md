# 工程部网页手册独立采集设计

用户已批准独立容器采集、本地文件中转、专用知识库方案，并确认每周采集一次、在项目子目录开发、验证后部署现有内网服务器。

## 边界与数据

采集器位于 `collectors/engineering_handbook/`，只访问指定手册网页，只写独立数据目录，不持有 RAG 管理凭据。用户已确认直接解析 HTTP 网页中的 FAQ_META/FAQ_DATA JSON，不执行网站脚本，保存问答、标签、来源路径、分类和内嵌文字。全文以来源路径去重，问答标明“网页整理要点”，正文标明“网页内嵌原文或节选，完整性未核实”。同源不同文字全部保留并关联问题，不宣称保留原始 Office/PDF 文件、图片或原文准确性，不自动访问网页标注的个人磁盘或内网路径。

按用户后续确认，文件以“可读资料名或问题标题＋完整 SHA-256”命名，标题过滤非法字符并限制长度；来源路径或完整问题标题参与指纹，避免排序变化或同名冲突。Markdown 内容不含每次抓取时间，避免无变化重建。采集时间、网页日期、关联信息放入清单和快照。

## 发布协议

独立目录包含 `versions/<版本>/documents/`、`manifest.json`、网页快照及结构化采集结果。清单包含协议版本、complete=true、文件路径/长度/SHA-256、条目数及唯一来源数。写完后原子替换 `CURRENT.json`，版本目录发布后不可修改。未完成采集不更新指针；空结果、计数不一致、内嵌文字缺失均失败。异常大量减少（超过上一版 20%）拒绝发布并记录原因，等待排查。保留历史版本以供回滚。

## 知识库读取

Worker 环境 `RAG_LOCAL_SOURCES` 映射来源标识到允许读取的根目录。新增 `/local/test`、`/local/scan`、`/local/read`，沿用内部令牌。发布目录扫描返回固定 snapshot，后续读取必须使用该版本；校验清单、文件哈希及禁止符号链接/越界/超过 50 MiB。普通目录也支持稳定读取，扫描失败不返回完整标记。

Rust 任务增加 `source_kind`（默认 smb）和 `source_id`；旧 SMB 配置兼容。复用现有增量发布、定时、互斥、目标不重叠及删除保护逻辑，删除前复核当前完整来源。网页提供来源类型与本地来源标识，隐藏本地来源不需要的 SMB 凭据字段。

## 运行与验收

采集每周一次，默认周一 02:00 Asia/Shanghai，首次启动立即采集；失败每小时重试，不推进成功日期。知识库每小时读取已发布版本，来源内容未变时跳过 embedding。采集器不发布端口，Worker 只读挂载目录。专用库名“工程部手册”，不修改现有 OpenClaw Key 的授权配置。

测试覆盖去重、来源关联、缺失/冲突全文、发布失败保留旧版本、计数骤降保护、重复采集稳定性、固定版本读取、路径和鉴权、同步增删改与故障保护、SMB 回归及桌面/手机页面。部署先核实实际服务与 Compose，备份完整数据和配置，构建验证后只更新必要服务；最后验证真实采集、首次索引、重复跳过及 MCP 限定库检索。SSH 连接方式尚待用户提供，不据此停止本地开发。
