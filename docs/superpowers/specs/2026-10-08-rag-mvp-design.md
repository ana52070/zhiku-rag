# RAG 与 MCP 服务 MVP 设计

## 目标与边界

建立带中文 Web 管理页面的知识库服务，支持文件上传、配置 embedding 模型、检索调试、MCP 工具和 Docker 部署。用户已确认开始实现 MVP。尚未回答的选择按明确披露的默认方案执行：仅本机访问、兼容 OpenAI 的 embedding HTTP API、TXT/Markdown/文字 PDF/DOCX，暂停业务而保留管理入口。没有账号体系、多租户、OCR、生成式问答和本地模型下载。

## 架构

FastAPI 提供管理 API 和静态前端；官方 MCP Python SDK 1.x 提供 Streamable HTTP 工具。SQLite 保存模型配置、文件、文本分段和向量。数据目录持久化到 Docker 卷。每次数据库操作使用独立连接。单进程服务以异步互斥锁协调上传、删除、模型切换与重建。

## 文件与索引

上传限制 10 MiB；TXT/Markdown 使用 UTF-8，PDF 提取文字，DOCX 提取段落和表格。不执行上传内容。原文件保存为随机 ID 文件名，原名称仅作为显示信息。文本分段默认 800 字符，重叠 120 字符，最多 2000 段。上传先保存并解析，随后调用模型；失败保留文件和可重试状态。重新索引采用先生成、后事务替换，失败不写入部分向量。

模型配置包含接口基础地址、模型名称、API Key。支持连接测试、密钥保留和清除。密钥使用数据目录独立密钥文件加密保存，API 不返回原值。接口或模型变化使所有旧索引失效；提供逐文件和批量重建。检索仅使用当前配置且启用的文件，按余弦相似度返回片段、文件名称与分段编号；不存在最低相关度保证。

## 服务与访问

业务开关暂停上传、检索和索引重建；管理界面、配置与恢复仍可访问。可单独启停文件检索或删除文件。默认绑定 127.0.0.1。管理员令牌保护管理 API，MCP 令牌独立保护工具入口；两者通过环境变量配置。浏览器使用会话内存保存管理员令牌，刷新后重新输入。跨站写请求拒绝。

MCP 工具：search_knowledge(query, top_k)、list_documents()、get_document(document_id)。文件读取工具必须尊重业务与文件启用状态；MCP 不暴露管理操作。

## 前端设计

采用用户指定的 anthropics/frontend-design Skill。界面模拟资料工作台，以文件列表、分段状态和来源片段为主视觉。左侧导航、右侧工作区：知识库、检索试验、模型配置、服务与接入。配色：纸白 #F7FAFC、墨蓝 #17324D、海蓝 #1565A8、淡蓝 #E8F1F9、石灰 #647789、警示红 #B53643。中文使用系统等线/微软雅黑，标题和正文明确字号层级；内容左对齐。操作具备加载状态、可见焦点、错误提示与空状态说明；移动端转为顶部导航。

## 验证与交付

使用 unittest 和真实 SQLite、真实 HTTP 测试客户端验证上传、检索排序、配置变更失效、失败重试、暂停、密钥脱敏、认证与删除。embedding 外部调用使用受控 HTTP 响应测试边界；不将该结果声称为真实模型质量验证。用真实 MCP 客户端验证初始化、工具发现和调用。浏览器检查桌面和移动端；Docker 实际构建、启动、健康检查与卷持久化。分阶段 Git 提交：设计基线、后端闭环、管理界面、部署与验收。
