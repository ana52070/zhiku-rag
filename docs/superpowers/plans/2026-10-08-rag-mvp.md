# RAG MVP 实现计划

> 执行方式：本会话按 executing-plans 逐项实现，不委派子代理。每一阶段验证后提交。

**目标：** 完成可运行的中文 RAG 管理服务和 MCP 检索工具。

**架构：** FastAPI 与 MCP SDK 共用知识库服务，SQLite 本地持久化。网页无需独立构建，Docker 使用单服务。

**技术栈：** Python 3.10+、FastAPI、MCP SDK 1.13.1、httpx、pypdf、python-docx、cryptography、原生 HTML/CSS/JavaScript。

**设计依据：** `docs/superpowers/specs/2026-10-08-rag-mvp-design.md`

## 全局约束

- 上传最多 10 MiB，文本最多 2000 段。
- 分段 800 字符，重叠 120 字符。
- 模型更换使旧索引失效。
- 原文件、密钥与数据库只进入忽略的数据目录。
- 默认仅绑定本机；Docker 默认发布到 127.0.0.1:8000。
- 中文界面、中文说明，关键操作失败必须可恢复。

## 阶段一：后端闭环

文件：`app/storage.py` 持久化，`app/documents.py` 解析，`app/embedding.py` 模型 HTTP 调用，`app/service.py` 索引与检索，`app/main.py` HTTP 与 MCP，`tests/test_service.py` 行为测试。

接口：`create_app(data_dir, embedder)` 返回 FastAPI 应用；embedding 的 `embed(config, texts)` 返回二维浮点列表；管理 API 前缀 `/api`，MCP 入口 `/mcp`。
